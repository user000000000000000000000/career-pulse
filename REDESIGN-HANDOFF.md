# Передача редизайна «Пульс Карьеры»

Изменения подготовлены от `origin/main` (`173a32a`), с переносом актуального
редизайна из `redesign-demo` (`6a6fdd9`). Исходная демоветка сохранена.

Включены обновлённая главная, личный кабинет, десять блоков диагностики,
маскот и анимации, письмо в будущее, результаты и карьерный маршрут.

Сохранены изменения основной ветки: расчёт и тайбрейк подбора профессий,
тесты подбора, раскрытие образовательных программ перед PDF-печатью,
диаграммы блоков, SEO и правовая навигация. Карьерный маршрут строит
курированный план работодателя и поддерживает ранее сохранённые планы
с массивом `steps`; отметки обоих форматов сохраняются в профиле.

Изменения не включают `.env`, настройки Vercel, deploy workflow,
изменения базы данных или удаление файлов основной ветки. Деморежим
включается только при сборке/запуске с `--mode demo`; обычная сборка
сохраняет подключение к рабочим API и авторизацию.

## Проверка

Из `frontend`:

```sh
npm ci
npm test
npm run check:arch
npm run build
npm run build:demo:vercel
node scripts/check-result-explanations.mjs
```

Для браузерных проверок установите Playwright и Chrome. Можно указать
уже установленный Playwright через `PLAYWRIGHT_MODULE`.
Запустите `npm run dev:demo`, затем в другом терминале:

```sh
node scripts/check-handoff.cjs
node scripts/check-test-flow.cjs
node scripts/check-demo.cjs
```

`QA_BASE_URL` позволяет выбрать другой адрес локального демосервера.
Проверки работают с изолированными локальными данными. Снимки и отчёты
сохраняются в игнорируемой папке `frontend/design-preview/`.
Доступность рабочего Supabase, реальная доставка заявок и внешний OAuth
не проверяются этими локальными сценариями.

Проверено 18 ноября 2026: девять тестов расчётов, архитектура, обычная
и изолированная демосборки, 111 проверок страниц и 15 сценариев,
69 проверок адаптивных страниц с дополнительной проверкой сохранения
профиля, обоих форматов маршрута и PDF-печати. Все десять блоков пройдены
через реальные элементы формы с контрольными точками; блок 7 дополнительно
пройден с нуля после исправления промежуточного рендера последнего кейса.
Проверка новых секретов в составе коммита не выявила находок.
